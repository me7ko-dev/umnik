# Умник

Безкрайна игра за трениране на ума: смятане, редици, уравнения, памет, внимание и мисловни задачи.
Трудността расте с всеки верен отговор и пада след грешки.

**Играй:** https://me7ko-dev.github.io/umnik/

- **Хранилище в GitHub:** https://github.com/me7ko-dev/umnik
- **Папка на компютъра:** `C:\Users\roika\Projects\umnik`
- **Частно копие (Artifact):** https://claude.ai/artifact/4yhRCwu2sj6o9uoU6M4X7E

## Режими
- **Безкраен:** 3 живота и таймер. Всеки 10 верни подред връщат живот.
- **Дзен:** без часовник и без край.
- **Спринт:** 90 секунди — колкото повече верни, толкова повече точки.

## Видове задачи
Смятане · Редици · Уравнения · Сравнение · Дроби и проценти · Памет · Цветове · Кое е различното · Внимание · Мисловни задачи

## Как се пуска
- **В интернет:** отвори https://me7ko-dev.github.io/umnik/ (работи и на телефон).
- **На компютъра:** двоен клик на `index.html` в папката.

## Как се променя
1. Промените се правят в `game.html`.
2. `sh build.sh` сглобява `index.html` (това е страницата за браузъра и GitHub Pages).
3. `git add -A && git commit -m "..." && git push` — сайтът се обновява след около минута.

Рекордите и статистиката се пазят в браузъра (localStorage).
